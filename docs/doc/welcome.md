# 欢迎

欢迎使用 SYLU Educational Office Accesser。

这是一个面向沈阳理工大学学生的移动端教务系统客户端。它把课表、考试、成绩、绩点、第二课堂和教务通知放在一个移动端应用里，并尽量把数据保存在本地，减少等待和额外服务依赖。

## 新用户导读

第一次使用时，先进入[登录](./login.md)页面，使用教务系统账号完成登录。如果教务系统要求验证码，应用会在登录流程里提示输入。

登录后应用会同步教务数据到本地。同步完成后，可以先从[课表页面](./course-timetable.md)查看当前周课程，再进入[课表总览](./course-overview.md)添加自定义课程、处理课程导出或使用 AI 生成课程配置。

如果需要追踪学业状态，可以查看[考试](./exam.md)、[成绩与 GPA](./gpa.md)和[教务通知](./academic-notice.md)。第二课堂相关内容可以在[第二课堂](./second-class.md)页面通过 VPN 托管能力查询。

想调整使用体验时，可以进入[设置](./settings.md)，配置主题颜色、首页模块、课表周末显示、小组件样式和同步周期。

::: tip
想调整首页显示内容或整体观感，可以通过[外观设置](./settings.md#外观设置)里的“主题色”“系统主题”和“底部栏定制”完成；如果希望数据自动保持更新，也可以在[同步设置](./settings.md#同步设置)中设置“同步时长”。
:::

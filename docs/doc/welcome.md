# 欢迎

欢迎使用 SYLU Educational Office Accesser。

这是一个面向沈阳理工大学学生的手机教务助手。它把课表、考试、成绩、绩点、第二课堂和教务通知放在一起，并尽量把已经更新过的信息保存在手机上，减少等待。

## 它能帮你省下什么

你不用在教务网的不同页面之间来回寻找，也不用临时翻聊天记录确认课程安排。打开应用，就能从今天的课程开始，继续查看考试、成绩、绩点、第二课堂和教务通知。

### 出门前看一眼

首页会告诉你今天上什么课、在哪间教室、现在是第几周。安卓手机还可以添加“今日课程”桌面小组件，不打开应用也能看到当天安排。

### 课表有变化时及时确认

遇到调课、课程调整或考试提醒，可以在教务通知里集中查看；课表不确定时，刷新后再确认当前周次和课程详情。通知还会区分已读和未读，方便先处理新的消息。

### 查成绩时少翻几页

想找一门课就搜索课程名或老师，想排查需要关注的课程就筛选“挂科”或“补考”。打开详情，还能回看同一门课过去的成绩变化。

### 把零散安排整理成自己的课表

临时课程、社团安排或其他需要记住的时间，都可以自己添加、修改或删除。整理好后，可以保存成文件，或者直接加入手机日历。

如果不想手动填写，也可以提供一段课程安排文字或一张课表图片，让应用帮你整理课程信息；保存前请检查上课周次、节次和教室。

### 不在学校也能查看第二课堂

完成登录后，可以查看思想成长、实践实习、创新创业、志愿公益和文体活动等类别的已获分数与完成进度，方便你知道还差哪些内容。

## 常用功能

- **首页**：查看教学周、今日课程、学期进度和教务通知。
- **课表**：查看本周或其他周次的课程，点开课程可查看教师、学分、时间和地点。
- **课表整理**：添加自己的课程，处理课程冲突，隐藏暂时不想看的课程，并加入手机日历。
- **考试**：按课程、老师、学期、通过情况或学位课查找记录，查看考试详情和历史变化。
- **成绩与绩点**：查看整体情况，也可以展开查看每项统计由哪些成绩组成。
- **第二课堂**：查看各类活动和分数；在校外使用时，按页面提示完成登录即可。
- **设置**：调整明暗模式、主题色、首页入口、周末课程显示和信息更新间隔。

## 新用户导读

第一次使用时，先进入[登录](./login.md)页面，使用教务系统账号完成登录。如果教务系统要求验证码，应用会在登录流程里提示输入。

登录后应用会更新教务信息并保存在手机上。更新完成后，可以先从[课表页面](./course-timetable.md)查看当前周课程，再进入[课表总览](./course-overview.md)添加自定义课程、处理课程导出或整理课程信息。

如果需要追踪学业状态，可以查看[考试](./exam.md)、[成绩与绩点](./gpa.md)和[教务通知](./academic-notice.md)。第二课堂相关内容可以在[第二课堂](./second-class.md)页面按提示登录后查询。

想调整使用体验时，可以进入[设置](./settings.md)，配置主题颜色、首页入口、课表周末显示、小组件样式和信息更新间隔。

::: tip
想调整首页显示内容或整体观感，可以通过[外观设置](./settings.md#外观设置)里的“主题色”“系统主题”和“底部栏定制”完成；如果希望信息自动保持更新，也可以在[同步设置](./settings.md#同步设置)中设置“同步时长”。
:::

## 4.0.0 (2025-06-19)  

感谢诸位三年以来对 SYLU-EOA 的陪伴与支持。一辈子的承诺如脆纸一样易碎，但迷途之子终会找到属于自己的路。  

以下为 SYLU-EOA 4.X 的更新日志：  

1. 支持 iOS 平台。  
   在iOS安装前，你需要学习如何为ipa包进行签名。  
   尽管签名仍需自理，但我们终于朝着跨平台迈出了第一步。  

2. 移除了照片签名、图书馆预约、第二课堂查看、系统日历导出  
   由于iOS的系统日历导出功能有一定bug导致此功能无法正常使用，等待修复后会在未来的某个小版本里回归。  
   二课，图书馆功能与教务系统集成度低，故决定移除。  
   有些功能，终究适合留在旧时光里。  

3. 重新设计同步机制  
   同步失败不再闪退，此版本经验证可彻底解决 3.X 的同步问题  

4. 删减不必要的动效  
   尽管电报的日夜切换很帅很酷，但为了跨iOS平台以及更加流畅自然的动画，我终究决定将其移除。  

5. 更换应用包名  
   4.X 与 3.X 可以共存，但从此以后，3.X 将不再维护。  

6. 开放了数据源切换的能力  
   在 4.X 中，任何人都可以编写代码以兼容自家学校的教务系统。  

阳光穿过夏天的绿叶，留下一张张独特的风景。三年青春转瞬即逝，如此灿烂，如此艳丽。

# 架构特性

SYLU Educational Office Accesser 采用开源、本地优先的移动端架构，面向沈阳理工大学教务场景构建。

## 开源可定制

源代码开放，便于按真实校园场景继续扩展和定制。

::: tip
如果想了解项目实现或参与改进，可以通过[进入设置](./settings.md#进入设置)中的“关于系统”打开“查看源代码”；遇到问题也可以使用“邮件反馈”联系维护者。
:::

## 无第三方服务器

应用不依赖第三方服务器中转教务数据，登录、同步和展示围绕本地数据展开，减少隐私风险。

## 离线优先

教务数据同步到本地后，常用页面可以快速打开。同步失败但本地已有数据时，应用会尽量继续展示可用数据。

## Kotlin Multiplatform

项目基于 Kotlin Multiplatform 构建，Android 和 iOS 共享主要业务逻辑。平台差异能力放在对应平台目录中实现，例如 Android 小组件、系统日历写入等。

## Room 与 MMKV

数据层使用 Room 保存课程、考试、成绩、GPA、第二课堂、教务通知和同步记录，使用 MMKV 保存登录信息、设置项、AI 配置和第二课堂配置。同步失败但本地已有数据时，应用会尽量继续展示可用数据。

## 插件化教务后端

教务网络能力拆分为独立的 EOA-Lib。核心模块定义统一的客户端接口和数据模型，沈阳理工大学教务系统只是其中一个实现，因此后续可以通过新增适配器扩展到其他教务系统。

## 轻量构建

构建流程经过体积优化，Android 安装包约 9M，iOS 安装包约 25M。应用保留原生移动端体验，同时控制安装包大小。

## Orbit MVI 与 Ktor

应用状态管理采用 Orbit MVI，页面逻辑以状态和副作用拆分；网络请求统一基于 Ktor Client，便于跨平台复用和调试。

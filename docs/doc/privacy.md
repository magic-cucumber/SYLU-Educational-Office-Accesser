# 用户协议和隐私政策

本页面集中展示 SYLU - EOA 的用户协议和隐私政策。

## 用户协议

欢迎使用 **SYLU - EOA**（以下简称“本应用”）。本应用由 **kagg886**（以下简称“开发者”）开发和维护，是面向沈阳理工大学相关用户的开源教务辅助工具。本应用是独立的第三方客户端，与沈阳理工大学、学校教务处、第二课堂系统及其他学校信息系统不存在隶属、代理或官方授权关系。

在使用本应用前，请仔细阅读并理解本协议及《隐私政策》。你点击“同意并继续”、安装、启动或继续使用本应用，即表示你已阅读、理解并同意接受本协议；如果你不同意，请停止使用本应用。

### 一、本服务的内容

1. 本应用可以使用你选择的学校系统账号，访问相关学校系统并在本地展示用户资料、校历、课程表、考试安排与成绩、绩点统计、教务通知等信息。
2. 本应用提供第二课堂信息查询功能。该功能可能通过学校内网、WebVPN、统一身份认证或第二课堂系统进行登录，并可能需要额外的密码、验证码或二次验证信息。
3. 本应用支持在本地添加、编辑和删除自定义课程，进行课程冲突查看，并将课程表导出为 ICS 文件或写入系统日历；也支持按用户选择的字段导出考试或成绩数据。
4. 本应用可以在设备上缓存已同步的数据，以支持离线查看；部分平台还提供今日课程桌面小组件。
5. 本应用提供日志查看、日志导出、问题反馈、公告、友链和版本更新检查等辅助功能。公告、友链、版本信息及应用内打开的外部网页可能来自第三方网站。
6. 本应用提供可选的 AI 课程录入辅助功能。你可以在设置中自行配置兼容 OpenAI 接口的模型服务，用于根据文字或图片识别课程信息并生成本地自定义课程；该功能不是学校官方成绩或课表服务。

### 二、账号、密码与授权

1. 你只能使用本人拥有或已获得合法授权的学校账号，不得使用他人账号，也不得将账号、密码、会话凭据或验证码提供给其他人。
2. 当你在本应用中登录时，即表示你授权本应用按照你选择的功能向相应学校系统发起登录、同步和必要的查询请求。应用可能会根据同步设置自动刷新数据；部分操作（例如将教务通知标记为已读）会向学校系统提交请求。
3. 你应遵守学校信息系统、校园网络、WebVPN、统一身份认证及第二课堂平台的相关规则。你应自行确认使用本应用访问这些系统符合学校的管理要求。
4. 你应妥善保管账号和密码，并对使用本人设备、账号和凭据进行的操作负责。因设备丢失、密码泄露、共享账号或其他可归责于你的原因造成的损失，由你自行承担相应责任。

### 三、用户行为规范

你不得利用本应用或通过修改、包装本应用实施以下行为：

1. 未经授权访问、查询、收集、披露或传播他人的账号信息、个人信息、成绩、课程或其他数据；
2. 绕过学校系统的访问控制，进行暴力破解、批量抓取、恶意刷请求、攻击、干扰或其他可能影响系统稳定性的行为；
3. 违反法律法规、学校规章制度、相关平台服务条款或公序良俗；
4. 侵犯开发者、学校、教师、同学或其他第三方的知识产权、隐私权及其他合法权益；
5. 将本应用、导出的数据或 AI 生成结果用于任何违法、误导他人或损害他人权益的用途。

### 四、数据、设备存储与第三方服务

1. 本应用当前不提供独立的应用账号系统。登录凭据、会话信息、第二课堂登录信息、已同步的教务数据、应用设置、日志和 AI 模型配置等内容会根据功能需要保存在你的设备本地，具体处理方式以《隐私政策》为准。
2. 退出登录会清除登录凭据、用户资料、课程、考试/GPA、第二课堂数据及相关同步数据，其中自定义课程也会被清除。系统通知、日志、应用设置和已保存的 AI 模型配置不一定随退出登录一并清除，请根据应用页面或系统提供的功能另行处理。
3. 如果你启用 AI 课程录入功能，应用会将你主动提交的课程文字或图片，以及完成课程时间识别所需的学期日期等内容，发送至你自行填写的模型服务地址。模型名称、API Key 和服务地址由你自行提供并保存在本地；开发者不控制该模型服务商如何处理你的请求，你应先阅读其隐私政策和服务条款，不要提交不必要的敏感信息。
4. 本应用可能访问学校官方系统、Gitee、应用文档或其他外部网站。外部网站的内容、可用性、隐私规则和服务条款由相应运营方负责；通过外部链接进行的操作不代表开发者对其作出保证或承担责任。
5. 你主动使用邮件、QQ群或日志导出功能进行反馈时，相关内容会由你选择的邮件、即时通信或系统分享服务处理。请在发送前检查日志和导出文件中是否包含账号、个人资料、课程、成绩或其他不希望披露的信息。

### 五、服务限制与免责声明

1. 本应用展示的数据主要来自学校系统或用户自行输入。受网络连接、学校系统维护、验证码、接口变化、同步延迟、解析错误、设备环境等因素影响，数据可能缺失、过期、不完整或与学校页面不一致。涉及选课、考试、成绩、学籍或其他正式事项时，必须以学校官方系统及学校正式通知为准。
2. 本应用按现状提供，开发者会尽力维护功能，但不保证服务持续可用、数据实时准确、始终兼容所有设备或及时适配学校系统及第三方服务的变化。
3. 本应用不是学校官方系统，也不保证你的登录一定成功、学校系统一定允许访问，或第二课堂、WebVPN、统一认证等第三方系统始终可用。
4. AI 识别和生成结果仅用于辅助录入，可能出现遗漏、误识别或虚构内容。你应在保存课程前自行核对课程名称、教师、教室、周次、星期和节次，不能仅凭 AI 结果作出影响学业安排的决定。
5. 在法律允许的范围内，因你违反本协议、相关平台规则或未核对应用展示/AI 生成结果而产生的损失，由你自行承担；本条不排除法律规定不得排除或限制的责任。

### 导言

_SYLU - EOA_ 是由 _kagg886_（以下简称“我们”）提供的校园信息工具。它主要作为客户端直接访问沈阳理工大学教务系统、团委网及校园 VPN，帮助您查看和整理课程、考试、成绩、第二课堂等信息。

部分数据会在您的设备上保存；当您使用相关功能时，数据会发送至对应的学校系统、您配置的 AI 服务、崩溃报告服务或操作系统服务。AI 数据共享和崩溃诊断上传是可选功能，默认关闭，您可以在首次引导或设置中分别启用、禁用。请在使用前阅读本政策，并根据需要选择是否使用相关功能。

如对本政策或个人信息处理有任何问题，请通过 **iveour@163.com** 与我们联系。

### 1. 我们处理的信息

#### 1.1 登录和身份验证信息

当您登录教务系统时，应用会处理您主动填写的学号、密码，以及登录后产生的会话 Cookie 或 Token。为了在下次使用时自动登录，这些信息会保存在设备本地。

当您使用第二课堂或校园 VPN 功能时，应用还会处理您填写的 VPN 密码、团委网密码，以及登录过程中由您输入的验证码或双因素认证验证码。密码和会话信息用于向相应学校服务完成身份验证。

#### 1.2 学校系统返回的业务数据

在登录并同步时，应用会根据您选择的功能向学校系统请求并在本地缓存以下数据：

* 个人资料，例如姓名、学院、专业、头像、电子邮箱、手机号码、学号及其他教务系统返回的资料字段；
* 校历、学年学期、课程表、课程名称、教师、教室、学分和课程时间安排；
* 考试、成绩、绩点、考试详情及教务通知；
* 第二课堂分类、活动名称、主办单位、时间、参与身份、参与人数和获得分数等数据。

您也可以在应用中手动创建课程或修改应用设置。这些内容用于本地功能。

#### 1.3 应用日志和错误信息

应用会在设备本地记录运行日志、错误信息、异常堆栈、应用版本和运行平台，用于显示日志、排查问题和改进应用。网络请求的调试日志可能包含请求地址、请求参数、响应内容或错误信息，因此在特定情况下可能包含您输入的内容、课程数据或其他敏感信息。自动崩溃诊断可能保留日志和崩溃文本中的原始内容，不保证自动删除其中的敏感信息。

当您主动通过邮件反馈，或主动复制日志后粘贴到 QQ 群等外部渠道时，日志会离开设备。发送前请自行检查并删除学号、密码、Token、Cookie 及其他不希望披露的内容。若不希望自动诊断包包含本地日志，请关闭“允许上传崩溃诊断”。

#### 1.4 可选的 AI 功能和数据共享授权

如果您在设置中配置 AI 模型，应用会在本地保存您填写的模型名称、服务地址和 API Key。API Key 是用于请求认证的敏感凭据；应用不会因为保存配置而将其发送到我们自建的统一服务器，但调用您配置的 AI 服务时会将其作为请求认证信息发送到对应服务地址。

使用课程文本识别或图片识别时，应用可能向您配置的服务地址发送您主动提供的课程文本、课程相关信息、当前学期第一周周一、学期结束日期、总周数或课程图片。保存 AI 配置时，应用会向您填写的服务地址发送固定的测试请求以验证配置是否可用；该请求使用您填写的 API Key，测试内容不应包含课程、成绩、图片或其他个人信息。

您可以在设置中开启或关闭 AI 功能。开启后，您主动使用课程文本识别或图片识别时，相关内容会发送到您填写的模型服务地址。关闭 AI 后，AI 功能入口和模型管理页面会隐藏，您无法在应用内新增或修改模型配置。保存模型配置时，应用会向您填写的模型服务地址发送用于验证配置的测试请求。

您可以在设置中随时撤回 AI 数据共享授权。AI 服务对请求、API Key、输入数据和返回数据的处理、保存、模型训练以及跨境传输由该服务提供方负责，请同时阅读其隐私政策和服务条款。请勿向不可信的 AI 服务发送身份证号、密码、Token 或其他不必要的敏感信息。

#### 1.5 文件和系统日历

* 导出成绩或课程表时，应用会把您选择的数据写入您在系统文件选择器中指定的 `.xlsx` 或 `.ics` 文件；导出的文件可能包含姓名、学号、课程、教师、教室、时间或成绩等信息。
* 选择“导出到日历”时，应用会按需申请日历读写权限，在设备的日历中创建并维护由本应用创建的课程日历及课程事件。为避免重复，应用可能读取该日历中的已有事件，并对其进行更新或删除；相关数据由操作系统的日历服务管理。
* 课程图片输入使用系统文件选择器；联网、应用更新和系统日历功能分别使用网络、安装更新和日历相关权限。

#### 1.6 可选的崩溃恢复和诊断上报

当应用检测到上一次运行发生崩溃，并且您在首次引导或设置中开启“允许上传崩溃诊断”后，应用会连接崩溃报告服务 `https://report-eoa.kagg886.top`，进行服务连通性测试、建立一次性加密传输会话，并上传崩溃诊断包。关闭“允许上传崩溃诊断”后，不会自动上传新的崩溃诊断包。该功能用于定位崩溃原因和协助恢复应用，不用于广告或用户画像。

自动诊断包可能包含：

* 崩溃信息、异常堆栈、运行日志、应用版本、运行平台和提交版本信息；
* 应用设置、初始化、同步、课程导出等配置；账号、密码、会话信息、VPN 密码、团委网密码和个人资料不会以原文写入诊断包；
* 经过处理的本地课程、考试、成绩、第二课堂、通知和同步数据。课程、教师、教室、考试名称、考试详情、通知、第二课堂名称及相关文本会被替换为不完整的内容；课程记录、时间、关联关系、记录标识、部分同步状态和成绩数值可能保留；
* AI 配置中的模型名称可能保留，模型 API Key 和服务地址不会写入诊断包，模型备注和描述不会写入；
* 应用运行时所产生的日志数据，包括运行状态、网络请求以及程序在运行期间捕获的错误等；
* 由本地头像数据计算得到的 SHA-256 编码标识，用于报告服务的令牌关联、去重或黑名单判断。

诊断包在发送前会压缩并加密，崩溃报告服务会在接收后解密并保存。应用会在上传结束或失败后删除本地临时上传文件。目前没有固定的自动删除期限，诊断包可能一直保存到服务运营方删除。您可以在设置中随时关闭“允许上传崩溃诊断”；关闭后不会自动上传新的崩溃诊断包。

### 2. 信息的使用

我们处理上述信息的目的仅限于：

* 完成教务系统、团委网和校园 VPN 的登录及数据查询；
* 在本地缓存和展示课程、考试、成绩、个人资料、第二课堂和通知；
* 提供课程编辑、成绩/课表导出、系统日历同步、应用更新和公告展示功能；
* 在您主动配置并使用 AI 功能时完成课程信息识别或结构化处理；
* 在您主动反馈或授权自动崩溃诊断上报时，协助定位崩溃和其他故障。

### 3. 信息的发送和共享

#### 3.1 按功能发送给外部服务

应用会在完成相应功能时直接连接以下类型的服务：

* 沈阳理工大学教务系统；
* 沈阳理工大学校园 VPN 和团委网；
* 用于检查更新、获取公告和链接列表的 Gitee 服务；
* 您在 AI 设置中自行填写的模型服务地址；
* 用于接收崩溃诊断和应用内反馈的崩溃报告服务 `https://report-eoa.kagg886.top`；
* 您主动打开或参与的 QQ 群、问卷、教育邮箱、GitHub、项目网站等外部页面。

上述服务会按照各自的隐私政策和日志规则处理请求中的账号信息、业务数据及常规网络信息（例如 IP 地址、请求时间和设备网络元数据），具体存储期限、存储地点和处理方式以相关服务规则为准。

#### 3.2 用户主动反馈

当您通过应用内反馈功能提交内容时，应用会将反馈正文、当前平台、应用版本，以及由您资料中的头像数据计算得到的 SHA-256 编码标识发送至 `https://report-eoa.kagg886.top`。该标识不是原始头像，但具有稳定性和可关联性，不能简单视为匿名数据。反馈服务会将反馈正文、该标识、平台和版本写入项目的 Gitee Issue；Gitee 及其服务商会按照其自身规则处理和保存这些内容。

崩溃反馈邮件会由您设备上的邮件应用发送，邮件内容可能包括您主动提交的崩溃日志、应用版本和运行平台。QQ 反馈功能会先将崩溃日志复制到剪贴板并打开 QQ 群，是否粘贴和发送由您决定。邮件服务商、QQ 及其他外部平台会按照其自身规则处理您提交的内容。

#### 3.3 网络安全提示

教务系统和校园 VPN 的部分请求使用 HTTPS；部分第二课堂服务可能使用 HTTP，其传输安全取决于校园网络和该服务本身。崩溃报告服务使用 HTTPS；AI 服务的传输安全取决于您填写的服务地址，建议仅使用 HTTPS。请在可信网络环境中使用，并不要在日志、反馈或 AI 请求中暴露不必要的敏感信息。

### 4. 信息的存储和期限

* 登录凭据、会话 Cookie/Token、应用设置、AI 配置等保存在设备本地的应用存储中；课程、成绩、考试、通知、第二课堂和日志等数据保存在设备本地数据库或缓存中。
* 数据通常会一直保留到您退出登录、删除对应配置/日志、清除应用数据或卸载应用；外部学校系统、Gitee、AI 服务和邮件/QQ 等平台的数据期限由其各自规则决定。
* 应用内反馈会被转交为 Gitee Issue；崩溃报告服务会保存其接收并解密后的诊断包。目前没有固定的自动删除期限，具体保留时间和删除流程以服务运营方的规则为准。
* 退出登录会清理登录信息及部分同步数据；日志、应用设置、AI 配置和已导出的文件可能仍然保留。若要彻底删除设备上的应用数据，请使用系统的“清除应用数据”或卸载应用，并单独删除您导出的文件及系统日历中的事件。
* 学校系统、Gitee、AI 服务或其他第三方平台中已经保存的数据，由相应服务的运营方按照其规则提供查询、更正和删除渠道；您可以通过 **iveour@163.com** 联系我们申请协助转交，但我们不能替代这些服务决定删除。

### 5. 信息安全

应用使用平台应用沙箱、本地数据库和本地存储能力保存数据，并在适用的网络连接中使用 HTTPS。登录流程会按对应学校系统的要求处理密码和会话信息。不同平台的本地保护机制可能不同，请同时做好设备和账户安全防护。

请妥善保管设备解锁凭据、教务账号密码、VPN 密码和 AI API Key，不要在共享设备上保存这些信息。由于调试日志可能包含请求或响应内容，分享日志前务必进行脱敏。

### 6. 您的选择和权利

您可以：

* 账号、密码、日历权限和 AI 配置分别对应登录、日历同步和 AI 功能，您可以根据需要进行设置；
* 在应用中退出登录、删除 AI 模型配置、清空应用日志，关闭“允许向 AI 服务发送数据”和“允许上传崩溃诊断”，或通过系统权限设置撤回日历权限；
* 通过系统清除应用数据、卸载应用以及删除导出文件，删除设备上由应用保存的内容；
* 通过学校系统或相关第三方服务查询、更正、删除由其保存的账号和业务数据；
* 通过 **iveour@163.com** 联系我们，提出与本应用本地数据处理有关的查询、删除或其他请求。我们会在核实请求后，根据适用法律法规和实际技术能力处理。

账户注册、注销和账号资料管理由对应的学校系统负责；本应用的退出登录用于处理本地登录状态及同步数据。
